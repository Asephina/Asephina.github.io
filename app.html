它是什么

Sympnoia（希腊语 σύμπνοια，「同息」——一同呼吸、气息相通）是一个可以 「属于某个人」的本地记录工具。桌面显示名为 Sympnoia， 应用内部名称与本地数据目录沿用早期的 Asephina。

主要功能

  • 行迹 · 文章 · 日记 · 心情 · 运动：五类记录折算成同一个量纲「行动熵」，长成一朵花、一条螺旋、一条河
  • 文档与日记：分类管理、正文编辑与排版，可一键导出 Word 文档留存备份
  • 番茄钟：前台服务计时，锁屏、切后台都不会中断
  • 步数统计：读取系统计步传感器，按天记录，无需联网
  • 凌薇 AI 对话（1.2 新增）：接上你自己选的模型接口，就能和「她」说话；人设卡可以自己写，也可以导入别人分享的
  • 多段对话 · 自定义头像（1.3.2 新增）：一个角色可以有很多段对话，自动命名、可改名、可删除；你和她的头像都能自己传
  • 数据全在本机：以明文 JSON、图片等文件形式保存，方便你自己备份与迁移
  • 完整备份与恢复：一键把全部数据（含图片、视频）打包成 zip 导出；换手机或重装后，选中那个 zip 就能恢复

凌薇 AI 对话（1.2 起 · 1.4.3 扩充）

底栏的第三栏「对话」是一个可以自定义的 AI 聊天界面。它本身不自带任何模型—— 你把任意一家 OpenAI 兼容接口的地址、密钥与模型名填进「AI 设置」，连接就通了。 内置了二十来家服务商的地址预设（DeepSeek / 通义千问 / Kimi / 智谱 GLM / 豆包 / 腾讯混元 / 百度文心 / 讯飞星火 / MiniMax / 阶跃星辰 / 硅基流动 / ChatGPT / Claude / Gemini / Grok / Mistral / Groq / Together / OpenRouter / 本地 Ollama / LM Studio）， 点一下自动填好，密钥由你自己去服务商那里申请。

  • 默认人设：内置一位「纳凌薇」，点「用」就能开始说话。她的设定写在程序内部、 不在界面上展示也不可修改，只留主题色、称呼与头像三项给你调。
  • 人设卡：自己建的角色按「任务 / 角色 / 外表 / 经历 / 性格 / 喜好 / 输出示例 / 备注」 分节填写，另有记忆片段与开场白。可以建很多张，换一张卡就换一个人； 导出的卡片不含任何密钥，可以直接发给别人。
  • 多段对话：一个角色名下可以有很多段对话，自动按第一句话命名， 可以改名、可以单独删掉某一段，像聊天软件那样翻。
  • 自定义头像 · 图片 · 表情包（1.4.3 扩充）：你和她的头像都能从相册选、裁成方图； 输入框左边的「＋」可以发照片，也可以收藏表情包、点一下直接发 —— 能不能真看见图片取决于你用的模型（设置里有「能看图」开关）。
  • 把记录分享给她：行迹、文章、日记、心情的每一条以及运动那一页都带分享按钮 —— 选一段对话，那条记录就作为你的发言发进去（对话里显示成一张两行的小卡片， 不会把整篇正文铺满屏幕），她按人设回应你。几千字的文章也不会被截断。
  • 她知道现在几点了：每次说话前都会带上真实的时间、星期、时段、 节日节气与纪念日；填一次城市后还会带上天气与温度。还有一个睡觉时段滑块， 这个时段里她不会主动开口，半夜你去找她也会先关心一句而不是催你睡。
  • 她会自己记住（1.3.6 增强）：每聊够 8 条消息（分几次聊也算），她把对话里值得 长期记住的事总结成短句存下来；条目能自己改、自己删、自己加，多了会自动折叠， 攒得太多还会自己精简一遍。
  • 她可以连着发好几条（1.3.4 新增）：一次想说的不止一句时，她会一条一条地发出来， 一个气泡接一个气泡，而不是把好几句挤成一大段；每条长短也不一样 —— 该说细的长一点，该应一声的就一两个词。回复的停顿与条与条之间的间隔都能自己调。
  • 人设卡可以填性别（1.3.3 新增）：男 / 女 / 不方便，决定界面上称呼这个角色时用 他 / 她 / ta。AI 之外的地方跟着「自定义设置」里的称呼走，AI 设置页与对话页 跟着当前人设卡走；两边对不上时统一用中性的 ta。
  • 她会先开口：你超过约 6 小时没说话，她会自己挑个话头来问候一句； 长时间不理就按 12 / 24 / 48 小时递增，至多 5 次，你一回应就重新计时。 只在应用开着时发生，不唤醒、不推送，也能在设置里彻底关掉。
  • 流式回复：回复逐字出现，随时可以停。
  • 连本地模型也行：地址填 http://电脑IP:11434/v1 就能连你自己电脑上的 Ollama， 这样连一个字都不会出你的局域网。
关于隐私与费用：只有你在这一栏里主动发出的内容，才会送达你自己填的那家服务商； 开发者没有服务器，不经手也看不到。API 密钥只存在本机，并且被排除在所有导出物之外—— 数据包、每日镜像、每日 Word 里都不会带上它。AI 的人设卡、记忆片段与全部对话 每天会自动导出一份（/Documents/Sympnoia/ai/ 一份覆盖式数据包， /Documents/Sympnoia/auto/ 一份滚动保留七天的 Word），也可以随时手动导出。 模型调用产生的费用由使用者自行承担。不打开「对话」这一栏，应用不会发出任何网络请求。

备份放在哪里（1.1 起）

所有导出都在应用数据之外的公共目录里，因此卸载应用不会把备份一起删掉：

  • /Documents/Sympnoia/　手动导出：Word 文档 + 数据包 .zip（不限份数）
  • /Documents/Sympnoia/auto/　每天自动导出的 Word。 自动导出一律是覆盖式的：记录与 AI 两种文档一起按天算，只留最近 7 天， 第 8 天起从最早那天整日覆盖 —— 不会随着天数越攒越多
  • /Documents/Sympnoia/mirror/　每天覆盖的原始数据镜像（单个 zip，只留最新 1 份）
  • /Documents/Sympnoia/ai/　每天覆盖的 AI 数据包（人设卡 + 记忆片段 + 全部对话 + 自动记忆 + 头像，只留最新 1 份）
  • /Documents/Sympnoia/restore/　从备份恢复前自动留的底（保留最近 3 份）
换手机时，把 /Documents/Sympnoia/ 这个文件夹拷到新机（或先传到网盘）， 再在新机上用应用内的「花房 · 数据 → 从备份恢复」选中 zip 即可。

为什么它值得信任

  • 开发者没有服务器：不注册、不登录，开发者拿不到你任何一条记录
  • 联网只为一件事：唯一会用到网络的是「对话」一栏里的 AI 聊天——接口地址与密钥全部由你自己填写， 应用里没有任何由开发者提供的密钥或中转服务器；不打开那一栏，就不会发出任何网络请求
  • 备份里没有你的密钥：API Key 单独存放，并被特意排除在「导出数据包 / 数据镜像 / 恢复留底」之外， 所以那些会落到公共目录的备份文件可以放心保存与分享
  • 没有广告、没有统计埋点、没有第三方 SDK
  • 只申请必要权限：身体活动（记步）、通知（计时提醒）、开机自启（恢复计时）、网络（仅 AI 对话，见隐私政策）；不申请相机、麦克风、位置、通讯录、短信、电话、全部文件读写等敏感权限
完整说明见 隐私政策。

安装步骤

  1. 点上面的按钮下载 Sympnoia-1.11.3.apk
  2. 在手机「设置 → 安全」里允许安装未知来源的应用（不同品牌路径略有差异）
  3. 打开下载好的 APK 完成安装
  4. 首次启动后按提示授予「身体活动」权限（用于记步）与通知权限（用于番茄钟提醒）
已经装过 1.0 / 1.1 / 1.2 / 1.4.3 的话，直接装 1.11.3 即可覆盖升级（同一个签名），记录不会丢。
